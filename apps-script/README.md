# 신청 폼 수신 설정 (한 번만 하면 됩니다)

Tally를 떼어내고 사이트에 직접 만든 폼으로 바꿨습니다.
신청이 들어오면 **구글 시트에 쌓이고, 동시에 이메일로 알림**이 옵니다.

가입할 외부 서비스는 없습니다. **구글 계정 하나만** 쓰면 됩니다.

전체 10~15분 정도 걸립니다. 순서대로 따라오세요.

---

## 1단계 · 구글 시트 만들기

1. <https://sheets.new> 접속 → 빈 스프레드시트가 열립니다.
2. 왼쪽 위 제목을 **`리드재인 신청 접수`** 로 바꿉니다.
3. 이 창을 닫지 말고 다음 단계로 갑니다.

> 시트 안에 표를 직접 만들 필요는 없습니다. 첫 신청이 들어올 때 제목 줄이 자동으로 생깁니다.

---

## 2단계 · 스크립트 붙여넣기

1. 같은 시트에서 상단 메뉴 **확장 프로그램 → Apps Script** 를 클릭합니다.
2. 새 탭에 코드 편집기가 열립니다. 안에 있던 기본 코드(`function myFunction() {}`)를 **전부 지웁니다.**
3. 이 폴더의 **`Code.gs`** 파일 내용을 전부 복사해서 붙여넣습니다.
4. 맨 위 `SHARED_SECRET` 값을 바꿉니다. 아무도 모르는 긴 문자열이면 됩니다.

   ```javascript
   var SHARED_SECRET = 'leadjaein-7fK2mQ9xRt4vZp8w';   // ← 이렇게 본인만의 값으로
   ```

   **이 값을 메모해 두세요.** 5단계에서 똑같이 입력해야 합니다.
5. 상단의 저장 아이콘(💾)을 누릅니다.

---

## 3단계 · 권한 승인하고 동작 확인

1. 편집기 상단 함수 선택 목록에서 **`setupTest`** 를 고릅니다.
2. **실행** 버튼을 누릅니다.
3. 권한 요청 창이 뜹니다. 처음 한 번만 나옵니다.
   - **권한 검토** → 본인 구글 계정 선택
   - "Google에서 확인하지 않은 앱" 경고가 나오면 → **고급** → **(안전하지 않음)으로 이동** 클릭
   - 스프레드시트와 메일 발송 권한을 **허용**

   > 본인이 직접 만든 스크립트라 이 경고가 나오는 게 정상입니다.
4. 시트로 돌아가보면 **`신청` 탭에 테스트 한 줄**이 들어와 있고,
   메일함에 **테스트 알림 메일**이 도착해 있어야 합니다.
5. 확인했으면 시트의 테스트 줄은 지워도 됩니다.

여기까지 되면 수신 쪽은 완성입니다.

---

## 4단계 · 웹앱으로 배포하고 주소 받기

1. 편집기 오른쪽 위 **배포 → 새 배포** 를 클릭합니다.
2. 톱니바퀴(⚙) → **웹 앱** 을 선택합니다.
3. 아래와 같이 맞춥니다.

   | 항목 | 값 |
   |---|---|
   | 설명 | `리드재인 신청 수신` (아무거나) |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

   > "모든 사용자"로 열어야 홈페이지에서 호출할 수 있습니다.
   > 주소를 알아도 2단계의 `SHARED_SECRET` 없이는 아무것도 저장되지 않으니 괜찮습니다.
4. **배포** 를 누르면 **웹 앱 URL** 이 나옵니다.
   `https://script.google.com/macros/s/AKfy.../exec` 형태입니다.
5. 이 주소를 복사해 둡니다.

---

## 5단계 · Vercel에 값 2개 넣기

1. <https://vercel.com> 접속 → `leadjaein-website` 프로젝트를 엽니다.
2. **Settings → Environment Variables** 로 들어갑니다.
3. 아래 두 개를 추가합니다. 적용 환경은 **Production, Preview, Development 전부** 체크합니다.

   | Name | Value |
   |---|---|
   | `APPS_SCRIPT_URL` | 4단계에서 복사한 `.../exec` 주소 |
   | `APPLY_SECRET` | 2단계에서 정한 `SHARED_SECRET` 과 **똑같은 값** |

4. 저장한 뒤 **Deployments → 맨 위 배포 → ⋯ → Redeploy** 를 눌러 다시 배포합니다.

   > 환경변수는 새로 배포해야 적용됩니다. 이 단계를 빼먹으면 폼이 작동하지 않습니다.

---

## 끝 · 실제로 확인

<https://www.leadjaein.com> 하단 신청 폼에 본인 정보로 한 번 넣어보세요.

- 메일이 오고, 시트에 줄이 쌓이면 **완료**입니다.
- "접수 설정이 완료되지 않았습니다" 메시지가 나오면 → 5단계 환경변수나 재배포를 확인하세요.
- "접수 처리 중 문제가 발생했습니다" 가 나오면 → `APPLY_SECRET` 과 `SHARED_SECRET` 값이 다른 경우가 가장 많습니다.

---

## 나중에 알아두면 좋은 것

**알림 받을 주소를 바꾸려면** `Code.gs` 의 `NOTIFY_TO` 를 고치고 저장 → **배포 → 배포 관리 → 수정 → 새 버전 → 배포**.
(새 배포를 만들면 주소가 바뀌니, 기존 배포를 "수정"해야 주소가 유지됩니다.)

**메일 발송 한도**는 무료 구글 계정 기준 하루 약 100통입니다. 신청 알림 용도로는 넉넉합니다.

**기존 Tally 응답을 옮기려면** Tally에서 CSV로 내려받아 `신청` 탭 아래에 붙여넣으면 됩니다.
